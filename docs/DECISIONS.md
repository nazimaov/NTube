Без входа показывается «Это видео для детей… только после входа в аккаунт» | Владелец: все детские видео открываются в обычном YouTube. Работа со входом на эмуляторе не проверена — там нет аккаунта; сообщение про вход показывается для любого «недоступного» видео без входа |
