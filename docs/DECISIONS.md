# Отступления от ТЗ

| Дата | Что изменено | Почему |
| --- | --- | --- |
| 2026-11-15 | NewPipeExtractor v0.27.1 вместо v0.26.5 | ТЗ требует самую свежую версию экстрактора (раздел 2) |
| 2026-11-15 | Media3 1.11.1 вместо 1.10.1 | Вышла более новая стабильная версия; API 1.x совместим |
| 2026-11-15 | AGP 9.5.1 со встроенной поддержкой Kotlin: плагин `org.jetbrains.kotlin.android` не применяется | В AGP 9 Kotlin встроен, отдельный плагин не нужен |
| 2026-11-15 | Иконки меню из `material-icons-core` 1.7.8: «Подписки» — сердце, «История» — календарь | В core-наборе нет иконок Subscriptions и History; полный набор иконок слишком большой |
| 2026-11-15 | `android.overridePathCheck=true` в `gradle.properties` | Путь проекта содержит кириллицу, без опции AGP отказывается собирать |
| 2026-11-15 | Методы репозиториев возвращают `AppResult<T>` (Success / Failure(AppError)) вместо `Result<T>` | `kotlin.Result` хранит Throwable, а наружу должен выходить только закрытый набор `AppError` |
| 2026-11-15 | `AppResult` и `AppError` лежат в `core:model`, а не в `core:common` | Нужны в чистом Kotlin-модуле с контрактами, без Android |
| 2026-11-15 | `AppError.ContentUnavailable` содержит enum `UnavailableReason`, а не строку | Экрану нужен локализуемый текст причины |
| 2026-11-15 | В `YouTubeRepository` добавлены `dashManifest(videoId, streamId)` и `channelPlaylists(...)`; у `videoDetails` есть `forceRefresh` | Манифест собирается классами экстрактора, которые не выходят из модуля; вкладка плейлистов отдаёт плейлисты, а не видео; перезапрос ссылок после 403/410 (4.4) |
| 2026-11-15 | ID канала хранится без префикса `channel/` (`UC…`, `@handle`); ссылку строит `channelUrl()` | Один ID для БД и навигации |
| 2026-11-15 | `trending()` с запасным киоском | В v0.27 киоск по умолчанию — `live`, а «В тренде» у YouTube нестабилен |
| 2026-11-15 | Токен страницы — сериализованный `Page` экстрактора в base64 | Не нужно хранить состояние пагинации в репозитории |
| 2026-11-15 | Иконка и баннер — векторные drawable | Своих растровых ресурсов пока нет; заменить на финальные при желании |
| 2026-11-15 | `PlayerController` отдаёт `player: Player` для PlayerView, есть `togglePlayPause()` и `retry()` | Поверхности видео нужен Player; кнопки панели и экран ошибки |
| 2026-11-15 | Программные видеодекодеры разрешены, только если на устройстве нет ни одного аппаратного | Иначе на эмуляторе без аппаратных декодеров нельзя проверить плеер |
| 2026-11-15 | Источники собираются через DefaultMediaSourceFactory, DASH-манифест передаётся как data:-URI | Нужный для субтитров API Media3 закрыт внутри пакета; так субтитры VTT подключаются штатно |
| 2026-11-15 | В `data:youtube` ошибки экстрактора пишутся в локальный logcat | Диагностика; никуда не отправляется |
| 2026-11-15 | Back обрабатывается в `onPreviewKeyEvent` корня и экрана плеера, а не `BackHandler` | На ТВ Compose при Back снимает фокус с элемента, событие до BackHandler не доходит |
| 2026-11-15 | Shorts-вкладка канала не показывается | Shorts — после MVP (раздел 1) |
| 2026-11-15 | `FilterChip` из tv-material используется с `@OptIn(ExperimentalTvMaterial3Api)` | В 1.1.0 API помечен экспериментальным, но стабильной альтернативы для фильтра нет |
