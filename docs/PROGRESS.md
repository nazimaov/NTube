- Меню долгого нажатия на карточке («Открыть канал», «Подписаться», «Не показывать канал», «Удалить из истории») — фаза 4, нужна библиотека.
- Автовоспроизведение следующего (плейлист / похожие) — фаза 4 вместе с историей.
- Даты старше недели показываются абсолютными («Nov 14, 2015») — так работает `DateUtils`.

Известные проблемы и перенесено:

- Первый запуск видео на эмуляторе — 9–30 с до первого кадра; чек-лист (≤ 5 с) проверить на реальном ТВ в фазе 6.
- Ряд «Похожие» по кнопке Вниз, автовоспроизведение следующего, сохранение позиции в БД, кнопки «Канал»/«Подписаться» — в фазах 3–4 (нужны карточки и БД).
- Панель скрывается только во время воспроизведения; на паузе остаётся.
- id тестового эфира со временем устаревает (см. комментарий в HomeRoute.kt).
- 4K на эмуляторе недоступен: декодер goldfish не поддерживает 3840×2160 — это ожидаемо.

Известные проблемы:

- Живые тесты с серверов GitHub могут падать на проверке «не бот» — так и задумано в 10.7.
